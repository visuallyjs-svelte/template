# Template - VisuallyJs Svelte

This is a starter app you can use as a base to build your own apps. It contains examples of how to:

- configure a zoomable and pannable canvas
- render nodes
- define the appearance and event bindings for edges
- add a miniview component
- add a controls component, providing buttons to undo/redo, zoom to fit, etc
- adda palette from which you can drag new nodes onto the canvas
- setup plugins in the canvas.


https://visuallyjs.com/demonstrations/template
